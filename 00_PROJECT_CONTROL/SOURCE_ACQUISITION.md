# Source Acquisition Protocol

## Purpose

Build an auditable corpus for historical-critical research on the Manusmriti.

## Source record requirements

Every source must have:

- Unique source ID
- Author or attributed author
- Title
- Original publication/manuscript date where known
- Edition date
- Editor/translator
- Language
- Source type
- Publisher/repository
- Stable URL, DOI, catalogue number, or manuscript identifier
- Date acquired
- File checksum where a local file is preserved
- Reason for inclusion
- Known limitations

## Evidence classes

P0 = primary textual foundation
P1 = primary comparative evidence
P2 = scholarly analysis
P3 = colonial/administrative history
P4 = modern reception and ideological history

## File naming

Use:

SOURCE-ID_author_shorttitle_year.ext

Examples:

M-002_jones_manu_1794.pdf
M-003_buhler_manu_1886.pdf

## Preservation rule

Do not alter source files. Preserve an original copy where legally appropriate. Any OCR, cleaned text, transcription, annotation, or extracted table must be stored separately and linked to the original source ID.

## Verification rule

A web copy is not accepted as authoritative solely because it is accessible. Record the edition and provenance first.

## Copyright rule

Prefer public-domain editions and lawful open-access copies. For copyrighted works, store bibliographic metadata and links unless the file is lawfully available to the project.

## Research rule

Never cite a source merely because it contains a claim. Verify the underlying passage whenever possible.
