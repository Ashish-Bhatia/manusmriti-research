# Manuscript Witness Notes

This file records information about individual Manusmriti manuscript witnesses and manuscript groups.

## Required fields

- Witness ID
- Repository
- Catalogue number
- Geographic association
- Script
- Language
- Approximate date
- Date basis
- Completeness
- Manuscript family / recension
- Commentary present
- Significant textual variants
- Additional or omitted verses
- Source reporting the evidence
- Confidence

## Critical distinction

Manuscript age does not automatically establish textual priority.

A later manuscript can preserve an older reading.

An older manuscript can contain secondary additions.

Textual priority must therefore be assessed from the complete evidence.
