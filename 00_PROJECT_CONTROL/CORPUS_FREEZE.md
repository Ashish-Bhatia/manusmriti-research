# Corpus Freeze Policy

## Principle

No substantive research conclusions will be drawn until the required source corpus has been assembled, catalogued, provenance-checked, and frozen.

## Acquisition phase

The project is currently in SOURCE ACQUISITION.

Permitted activities:

- Source identification
- Bibliographic verification
- Repository verification
- Lawful acquisition
- File integrity verification
- Metadata recording
- Checksum generation
- OCR quality assessment
- File organization
- Provenance documentation

## Prohibited before corpus freeze

- Historical conclusions
- Textual-critical conclusions
- Interpolation conclusions
- Translation conclusions
- Ideological conclusions
- Claims of deliberate falsification
- Claims that one recension is original
- Claims about historical social practice

## Source hierarchy

P0 = primary textual evidence
P1 = comparative primary evidence
P2 = traditional commentary
P3 = scholarly secondary evidence
P4 = colonial/administrative evidence
P5 = modern reception

## Original-source preservation

Original scans and legally acquired source files must never be overwritten.

Derived OCR, transcription, normalization and annotation must be stored separately.

## Corpus freeze requirements

Before research begins:

1. Required source inventory completed.
2. Each source assigned a unique source ID.
3. Bibliographic identity verified.
4. Provenance recorded.
5. Copyright/access status recorded.
6. Local files checksum-verified where applicable.
7. File readability assessed.
8. Missing sources explicitly documented.
9. Source limitations documented.
10. Corpus version tagged.

## Research start condition

Research begins only after an explicit CORPUS FREEZE decision is recorded.

Until then, all observations are acquisition notes, not substantive findings.
